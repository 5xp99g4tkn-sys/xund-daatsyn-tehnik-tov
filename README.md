# Хүнд даацын техник төв — GitHub Pages

## Файлын бүтэц

- `index.html` — үндсэн сайт
- `products.js` — техник, сэлбэг, тосны каталог болон харилцагчдын сэтгэгдлийн өгөгдөл
- `README.md` — deploy хийх заавар

## Бүтээгдэхүүн нэмэх / засах

`products.js` доторх `window.PRODUCTS` массивт шинэ объект нэмнэ.

- `kind`: `machine`, `part`, эсвэл `oil`
- `type`: ангилал
- `name`: бүтээгдэхүүний нэр
- `price`: үнэ; `0` бол “Үнэ тохиролцоно”
- `images`: зурагны URL-уудын массив
- `desc`: дэлгэрэнгүй тайлбар
- `specs`: `[["Үзүүлэлт", "Утга"]]` хэлбэрийн массив
- `note`: нэмэлт анхааруулга

## Харилцагчдын сэтгэгдэл нэмэх

`products.js` доторх `window.TESTIMONIALS` массивт шинэ объект нэмнэ.
Энэ нь “Манай харилцагчид” (`#customers`) хэсэгт карт хэлбэрээр гарна.

- `industry`: салбар (жишээ: “Уул уурхай”, “Барилга”)
- `text`: сэтгэгдлийн текст
- `name`: харилцагчийн нэр
- `role`: байгууллага, ажлын албан тушаал

> Анхааруулга: анхны `TESTIMONIALS` жишээ текстүүдийг бодит сэтгэгдэл,
> нэр, байгууллагаар солихоо мартуузай.

## GitHub Pages

1. GitHub дээр шинэ repository үүсгэнэ.
2. `index.html`, `products.js`, `README.md`-г repository-ийн үндсэн folder-т байршуулна.
3. **Settings → Pages → Build and deployment → Deploy from a branch** сонгоно.
4. Branch: `main`, folder: `/ (root)` сонгоод Save хийнэ.
5. GitHub Pages өгсөн URL-аар сайтаа нээнэ.

Энэ сайт нь backend шаарддаггүй тул GitHub Pages дээр шууд ажиллана. Үнийн саналын form нь статик демо бөгөөд бодит захиалга/мессеж хадгалах backend холбогдоогүй.
